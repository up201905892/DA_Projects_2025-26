Detailed Description

Result of a register allocation attempt.

colors[i] holds the register index (0..N-1) for web i, or SPILL_COLOR (-1) if web i was assigned to memory.

spilledWebs and splitRecords are complementary metadata used by the alternative algorithms. They make the output more processing-friendly and easier to justify in the project presentation.
