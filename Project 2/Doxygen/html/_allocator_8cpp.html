Write the allocation result to an output file.

Write allocation result to a file.

The output format follows the project statement. For spilling and splitting, extra metadata is appended in a simple line-based format.

Parameters
filenameOutput file path.
websVector of webs.
resultAllocation result.
numRegistersNumber of registers available in the input configuration. This parameter is kept for compatibility, but the output prints result.registersUsed.

@complexity O(W + A + M), where W is the number of webs, A is the number of register assignments, and M is the amount of metadata written.

Write the allocation result to an output file.

Format:

webs: W
web0: <ranges>
...
registers: R
r0: webX
...
M: webY

For alternative algorithms, additional processing-friendly metadata may be appended, for example:

# algorithm metadata
algorithm: spilling
spill_budget: 2
spilled_webs: 1
spilled: web3
Parameters
filenameOutput file path.
websWeb vector.
resultAllocation result.
numRegistersNumber of registers from configuration. Kept for compatibility; result.registersUsed is printed.

@complexity O(W + A), where W is the number of webs and A is the number of assignments written.
