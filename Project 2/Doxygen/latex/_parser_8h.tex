Parses range and register/\+algorithm input files. 

Handles two input formats:\+
\begin{DoxyItemize}
\item Ranges file:\+ "{}varname:\+ p1\+[,p2,...,pn]\+"{} where any point may optionally be marked with \textquotesingle{}+\textquotesingle{} for definition or \textquotesingle{}-\/\textquotesingle{} for last use.
\item Config file:\+ "{}registers:\+ N"{} /\+ "{}algorithm:\+ type\+[, K]\+"{} 
\end{DoxyItemize}
