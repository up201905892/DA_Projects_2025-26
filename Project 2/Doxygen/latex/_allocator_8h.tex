\doxysubsection{Detailed Description}
Register allocation algorithms operating on the interference graph. 

Supports four allocation strategies:\+
\begin{DoxyItemize}
\item BASIC:\+ Greedy graph coloring; fails hard on spill.
\item SPILLING:\+ Tolerates up to K spills to memory.
\item SPLITTING:\+ Splits up to K webs before attempting coloring.
\item FREE:\+ Optimized DSATUR-\/based coloring with integrated spilling. 
\end{DoxyItemize}
