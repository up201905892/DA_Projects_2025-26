Parse the live-\/ranges file. 

Parse the live-\/ranges input file.

Lines beginning with \textquotesingle{}\#\textquotesingle{} or empty lines are ignored.

Format per line:\+ 
\begin{DoxyCode}{0}
\DoxyCodeLine{varname:\ token1,token2,...,tokenN}

\end{DoxyCode}


Each token is a program line number, optionally followed by:\+
\begin{DoxyItemize}
\item \textquotesingle{}+\textquotesingle{} meaning definition/\+start of a value;
\item \textquotesingle{}-\/\textquotesingle{} meaning last use/\+end of a value.
\end{DoxyItemize}

A line may have no markers, one marker, or both markers. Multiple \textquotesingle{}+\textquotesingle{} markers or multiple \textquotesingle{}-\/\textquotesingle{} markers in the same range are rejected.

This parser accepts the full format described in the project statement. In particular, a live range is not required to contain both a \textquotesingle{}+\textquotesingle{} and a \textquotesingle{}-\/\textquotesingle{} marker. Some ranges may contain only plain line numbers because they describe intersection points between live ranges.
