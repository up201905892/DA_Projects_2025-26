\doxysubsection{Detailed Description}
Entry point for the Compiler Register Allocation Tool. 

Supports two execution modes:\+
\begin{DoxyItemize}
\item Batch mode:\+ my\+Prog -\/b ranges.\+txt registers.\+txt allocation.\+txt
\item Interactive mode:\+ my\+Prog (launches menu-\/driven UI)
\end{DoxyItemize}

Error messages are written to stderr; all other output to stdout or file.
