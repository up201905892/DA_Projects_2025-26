\doxysubsection{Detailed Description}
One live range for a variable. 

A live range is represented as a set/\+list of program points. According to the project statement, not every live range line must contain a \textquotesingle{}+\textquotesingle{} or \textquotesingle{}-\/\textquotesingle{} marker:\+ ranges that exist only because of intersections may contain plain program points only.

The fields start and end store the first and last program points in the input line, respectively. The boolean flags indicate whether those points were explicitly marked as a definition \textquotesingle{}+\textquotesingle{} or last use \textquotesingle{}-\/\textquotesingle{}.
